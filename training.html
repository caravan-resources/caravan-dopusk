📤 Массовый ввод из Excel
Заполни шаблон (по строке на каждый самосвал; ФИО должно точно совпадать с базой сотрудников) — можно на нескольких сотрудников и дат сразу. Загрузи файл — таблица развернётся ниже для проверки, после чего одной кнопкой сохранится как отдельные замеры.
⏱ Новый замер хронометража
Для машинистов экскаватора. Замеряется отдельно (по видео/скриншотам) — сюда вносятся уже готовые числа. Цикл одного ковша — время между выгрузкой 1-го и 2-го ковша.
🧮 Калькулятор по секундомеру ▾
Вводи отсечки секундомера по одной, в секундах (напр. 21.22) — таймер стартует в момент выгрузки 1-го ковша, поэтому отсечек всегда на одну меньше, чем ковшей. Случайно отсекли лишний раз — удалите одну из двух соседних строк и прибавьте её значение к оставшейся.
-
время погрузки, сек
-
ковшей
-
ср. цикл, сек
Отдельно от времени начала погрузки — позволяет разделить простой на «ждали подвоза» и «стоял, но не грузили».
Нужно только чтобы отчёт мог посчитать простои между самосвалами. Можно оставить пустым.

🎯 Требования по должностям — компетенции (тесты допуска + курсы обучения)
Сверка идёт по точному совпадению строки должности.
